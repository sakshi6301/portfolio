# Sakshi Hudge - Portfolio Website

A modern, responsive personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Smooth scrolling navigation
- Animated sections on scroll
- Mobile-friendly hamburger menu
- Contact form with validation
- Professional and clean UI/UX

## Sections

1. **Home** - Hero section with introduction
2. **About** - Professional background and career objectives
3. **Skills** - Technical skills categorized by type
4. **Projects** - Showcase of major projects
5. **Education** - Academic background
6. **Contact** - Contact information and form

## Setup Instructions

1. Download all files maintaining the folder structure
2. Add your resume PDF as `resume.pdf` in the root directory
3. (Optional) Add profile image in the `images/` folder
4. Open `index.html` in a web browser

## Deployment

### GitHub Pages
1. Create a new repository on GitHub
2. Upload all files
3. Go to Settings > Pages
4. Select main branch as source
5. Your site will be live at `https://yourusername.github.io/repository-name`

## Customization

- Update personal information in `index.html`
- Modify colors in `css/style.css` (CSS variables in `:root`)
- Add your actual contact details
- Replace placeholder links with real profiles

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- JavaScript (ES6+)

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
