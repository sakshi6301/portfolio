IMAGES FOLDER

This folder is for storing images used in the portfolio website.

Suggested images to add:
- profile.jpg (your professional photo)
- project screenshots (optional)
- favicon.ico (browser tab icon)

To use images in your portfolio:
1. Add image files to this folder
2. Reference them in HTML using: <img src="images/your-image.jpg" alt="description">

Current portfolio works without images, but you can enhance it by adding visuals.
